# Contributing to Arca

Thank you for your interest in contributing to Arca!

## Contributor Guides and Workflow

Before starting work, please review the contributor documentation:

1. **Governance & Review Gates**: Read [Governance Charter](docs/governance/index.md)
   for project invariants, architectural principles, and PR checklists.
2. **Development Environment & Setup**: See [AGENTS.md](AGENTS.md) and
   [Cross-Repository Development](docs/dev/cross-repository-development.md) for
   setting up a local Optics development worktree.
3. **Automated Testing**: Review [Testing Guide](docs/dev/testing.md) for running unit,
   headless UI, and integration test suites.
4. **Deliverable Acceptance**: Review [Acceptance Guide](docs/dev/acceptance.md) to
   ensure end-to-end user journeys pass verification.
5. **Distribution Packaging**: See [Distribution Packaging](docs/dev/packaging.md) for
   package guidelines and release artifacts.

## Documentation Governance

Documentation in this repository is managed under a formal governance protocol.
See [Documentation Governance](docs/governance/documentation/core/index.md) and
[4-Gate Routing](docs/governance/documentation/core/routing.md) before authoring
new documentation.
