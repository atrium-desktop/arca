# Lantern Documentation

Lantern is a file manager for Wayland, built on the
optics graphics stack. For the project pitch, feature list, and the
shortest path to a running build, see the root [README](../README.md).

## User documentation

The user-facing surface currently lives in the root
[README](../README.md): features, keyboard shortcuts, build and run
instructions, and a configuration overview.

## Contributor documentation

Contributor material — build internals, architecture notes, and the
documentation governance policy — lives under `docs/dev/`. It is
intentionally not linked from this page; open it directly when
contributing.
