# How-To Guides

How-to guides provide direct, task-focused instructions for accomplishing specific
goals with Arca.

## Topics

### Navigation & Management
- [How to Navigate and Browse Directories](navigate-and-browse.md) — Jump to
  paths, traverse history, filter listings, and manage tabs and bookmarks.
- [How to Manage Files and Use Trash](file-operations-and-trash.md) — Create
  folders, inline rename, copy/cut/paste, move to trash, and restore files.

### Inspection & Previews
- [How to Use Quick Look Preview](use-quick-look-preview.md) — Preview images,
  audio tags with cover art, directory summaries, and text code.

### Desktop Integration
- [How to Use the Portal File Picker](use-portal-file-picker.md) — Use Arca as an
  XDG Desktop Portal file chooser or invoke standalone CLI picking modes.

### Customization & Installation
- [How to Customize Appearance and Settings](customize-appearance-and-settings.md) —
  Configure light/dark themes, thumbnail generation, view modes, and `arca.conf`.
- [How to Install and Package Arca](install-and-package.md) — Install pre-built
  packages or compile and install Arca from source.
- [How to Troubleshoot Common Issues](troubleshoot-common-issues.md) — Diagnose
  Wayland connection errors, Vulkan GPU initialization, and portal routing.
