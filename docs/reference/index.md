# Reference

Reference documentation provides exact, factual specifications, schemas, tables,
and options for Arca.

## Topics

- [Command-Line Interface Reference](cli.md) — All CLI flags, modes, exit codes,
  and environment variables.
- [Configuration Reference](configuration.md) — Syntax, allowed values, defaults,
  and keys in `~/.config/arca/arca.conf`.
- [Keyboard Shortcuts Reference](keyboard-shortcuts.md) — Comprehensive shortcuts
  table for navigation, tabs, file operations, and preview.
- [Portal Prompter Protocol Reference](portal-protocol.md) — JSON schema and contracts
  for `--chooser-prompt` integration.
- [Glossary](glossary.md) — Canonical architectural and subsystem terminology.
